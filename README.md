# Bekirağaoğlu Sigorta — Wix → Vercel aktarımı

Bu proje, mevcut Bekirağaoğlu Sigorta Wix sitesinin Vercel/Next.js aktarımıdır. Kaynak site yayında kalırken önizleme için hazırlanmıştır. Alan adı ve e-posta DNS ayarlarına dokunulmamıştır.

## Kurulum

```bash
npm install
npm run dev
npm run build
```

Vercel'de bu repoyu Next.js projesi olarak içe aktarın. Form e-postası için `.env.example` içindeki değişkenleri tanımlayın.
